# Animal Sound Files

Place your animal sound files in this directory with the following names:
- cat.mp3
- dog.mp3
- lion.mp3
- monkey.mp3
- frog.mp3
- cow.mp3
- pig.mp3
- duck.mp3
- chicken.mp3
- sheep.mp3
- horse.mp3
- elephant.mp3
- bear.mp3
- tiger.mp3
- penguin.mp3

Recommended: Short (0.5-1s), gentle animal sounds suitable for children.
Format: MP3 or OGG for best browser compatibility.

You can find free animal sounds at:
- https://freesound.org/
- https://www.zapsplat.com/
- https://pixabay.com/sound-effects/animals/
